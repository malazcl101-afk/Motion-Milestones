HARBORNESTDIGITAL · MOTION & MILESTONES
QUICK START

1. Unzip the customer ZIP and keep all files in one folder.
2. Open index.html in a current desktop browser. Set your starting weight and optional goal in Customize & backup.
3. Use Weight progress, Body measurements, Workout log and Weekly habits to add records. The dashboard and reports update automatically.
4. Switch kg/lb or cm/in under Customize & backup. Saved values stay canonical; unit switches convert their display.
5. Download a JSON backup regularly. To move records to another device or browser, restore that backup there. Data does not sync automatically.
6. CSV exports are available for weight, measurements and workouts. The Insights page can print a summary.

WHERE YOUR DATA LIVES
The planner stores records in IndexedDB in the browser profile and device in which it is opened. Clearing browser data, using a private session, or changing devices can remove access. Keep a JSON backup in a safe place. No account, cloud database, or subscription is included.

PHONE / TABLET
Opening downloaded HTML on a phone may be restricted by your browser or file manager. For reliable mobile use and home-screen installation, place the unzipped folder on a static HTTPS host such as GitHub Pages, then open its URL in Safari or Chrome. On iPhone use Share > Add to Home Screen; on Android use browser menu > Add to Home screen/Install where offered. The app caches its files for offline access on HTTPS after the first successful visit. Your records remain on that device and browser, separate from desktop.

CUSTOMIZATION
Choose Ivory, Sage, Peach, Lilac or Midnight, two font styles, compact/comfortable/spacious density, rounded/square cards, wide/standard layout, enhanced contrast, and custom accent themes. Restore default appearance in the same screen.

TROUBLESHOOTING
Blank dashboard: demo starts with fictional records; set your starting point and add entries. A demo uses fictional records and a separate database.
Missing records: check you opened the same browser/profile/address; restore your latest JSON backup.
Import error: choose an unmodified JSON backup made by this planner. Restore replaces current records after confirmation.
Installation not offered: use HTTPS and a compatible browser, not a file URL. Installation is optional; the browser version works without it.
After clearing browser data: restore a backup. There is no remote copy.
Buttons or saving do not work: allow browser site storage, avoid private mode, and try a current version of Chrome, Edge or Safari.

This is a personal fitness organization journal, not medical, health or fitness advice. Workout calories are optional user-entered estimates; the planner does not calculate energy expenditure. No actual photos are stored; photo notes are descriptions.
