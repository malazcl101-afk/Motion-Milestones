Your quick start guide

Welcome

This guide walks you from download to your first progress report.

1 · Download and open

Unzip the customer ZIP. Keep index.html, app.js, style.css, icons and manifest together. On desktop, open index.html in a current browser.

2 · Set a starting point

Open Customize & backup. Enter your starting weight, optional goal and personal target date. Choose kg or lb before entering values.

3 · Log what matters

Add weight check-ins, body measurements and workouts. Create habits and tap the weekdays as you go. Use goals, badges and text-only photo notes for reflection.

4 · Read your progress

Dashboard and Insights calculate from saved entries. Progress is a directional comparison between your chosen start and goal. No medical interpretation is provided.

5 · Back up and transfer

Download JSON backup in Customize & backup. Save it safely. To move data, open the planner on the new browser/device and restore the JSON file. Records do not sync automatically.

6 · Phone and offline use

For reliable phone use, host the folder on an HTTPS static host such as GitHub Pages. Open the link in Safari/Chrome and use the browser Add to Home Screen/Install option when available. HTTPS enables offline caching after the first visit. File URL behavior varies.

7 · Personalize

Choose five themes including Midnight, custom accent colors, modern/editorial fonts, three spacing choices, card shapes, layout width and extra contrast. Restore default appearance at any time.

Troubleshooting

Empty customer dashboard is expected until you add records. Missing data usually means a different browser/profile/address or cleared browser storage. Restore your backup. Imports must be this planner’s JSON format and replace records after confirmation. Browser installation requires HTTPS; it is optional.

Privacy and limits

Data is local to your browser and device. No login, subscription, automatic sync, notifications or image storage. Calories are self-reported estimates. This is a personal organization tool, not medical or fitness advice. Contact HarborNestDigital via Etsy for purchase help.
